# Synthetic Azure rebuild evidence

These fictional files illustrate selected fields from the Azure rebuild
baseline and validation output. They use a placeholder subscription and
addresses reserved for documentation. They are samples for reading and testing
and are incomplete as inputs to the rebuild workflow.

- [Network identity](baseline/network_identity.json) shows the network
  information captured before a rebuild.
- [Post-rebuild validation](validation/post_rebuild_validation.json) shows
  how the report records reachability and overall status.

Keep real job output in the approved private evidence location.
